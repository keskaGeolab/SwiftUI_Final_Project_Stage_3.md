# ჩემი ბიუჯეტი — MyBudget

SwiftUI და SwiftData აპლიკაცია ხარჯების აღრიცხვისთვის.

## მოთხოვნები
- Xcode 15 ან უფრო ახალი
- iOS 17.0 ან უფრო ახალი

## გაშვება
1. გახსენით `MyBudget.xcodeproj`.
2. აირჩიეთ iPhone Simulator.
3. გაუშვით `Command + R`.

## ფუნქციები
- ხარჯის დამატება და ვალიდაცია
- SwiftData-ით ლოკალური შენახვა
- კატეგორიით ფილტრაცია
- ჯამური თანხის გამოთვლა
- ხარჯის წაშლა
- მონაცემების შენარჩუნება აპის ხელახლა გაშვების შემდეგ
